# Aster Finance

## Reference analysis
- Source: [Fizens finance SaaS template](https://fizens.framer.ai/), a commercial Framer template credited on-site to Made by Kota / LoganCee Studio. Reviewed homepage, `overview`, `features`, `pricing`, `about`, and `contact`; captured homepage at 1366×900 and 390×844. No source code or assets supplied under a reuse license; no source assets, brand names, copy, or code are reused.
- Observed structure: slim top navigation; left-aligned finance headline and CTA; right-side overlapping phone/app mockups; blue gradient trust panel and partner wordmarks; feature intro and bento cards; three alternating benefit rows with product illustrations; statistics; numbered steps in a pale-blue panel; testimonials; pricing plans with monthly/yearly choice; article cards; FAQ; blue closing CTA; multi-column footer. Inner pages include features, about/team/careers, pricing/comparison, articles, contact, integrations, downloads, and utility/legal pages.
- Visual evidence: mostly white canvas, cobalt/royal-blue gradient hero and CTA surfaces, very pale blue panels, dark navy text, soft rounded cards, pill controls, fine borders and restrained shadows. Spacious section gaps and centered section headings contrast with dense app-preview cards. Reference hero uses large multi-line display copy; its HTML ships Geist, Poppins, Instrument Sans, and Inter font declarations. Actual font assignment was not reliably observable, so this template uses Forma's shared Plus Jakarta Sans token.
- Interaction evidence: navigation links to section/page anchors; visible CTAs navigate to pricing/contact/download destinations; pricing exposes Monthly/Yearly options; FAQ questions are expandable; the publisher describes smooth animations and responsive layouts. No financial-app functionality is claimed or inferred from marketing copy. This template implements local anchor navigation, a mobile menu, interactive local pricing, native accessible FAQ disclosures, testimonial controls, and a signup dialog with local success feedback.
- Responsive assumptions: desktop keeps a side-by-side hero and wide bento layouts; tablet reduces columns and stacks product panels as needed; mobile collapses navigation to a menu, stacks cards/steps/pricing, and preserves comfortable type and touch targets. Behavior not visible in evidence is implemented conservatively.
- Typography, spacing, color, and surface tokens: Compact & Balanced Typography; 14px body and controls, 12px minimum visible UI text, 40–48px desktop hero using shared tokens and responsive clamp. Use semantic foreground/background/card/border/muted tokens; `--accent` drives the blue gradient and active controls. Rounded panels echo the reference without copying exact geometry.
- License/attribution: reference is a commercial Framer template, not a source-license grant. Original React/CSS, fictional Aster branding/data, and original CSS-built product illustrations only. No third-party imagery or source code copied. Lucide icons use the existing project dependency; Plus Jakarta Sans follows the shared package's SIL Open Font License attribution.
- Deviations: one original, self-contained landing page rather than reproducing every linked Fizens inner/utility page; all content, plans, testimonials, partner names, and feature claims are fictional/sample. Product app previews are decorative illustrations, not a working finance product. CTAs, pricing, FAQ, mobile navigation, and feedback work locally.
